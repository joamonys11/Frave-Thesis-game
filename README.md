## Setup in Unity

1.  Extract **fravecom.zip**.
https://drive.google.com/file/d/1MCtDT6X8QMe0Kfpn1MZMR9RQBqpYfyI9/view?usp=sharing
2.  Open the project in **Unity Editor**.
3.  If the scene does not open automatically, navigate to:

`fravecom/artest/Assets/scene/`

4.  Open the scene:

`Main.unity`

This scene contains the **main menu** of the game.

## Build Settings

1.  Open **Build Settings** in Unity.
2.  Select **iOS** as the target platform.
3.  Switch the platform to **iOS**.

> Note: The UI is already configured for **iOS display**.

## Running the Game

1.  Build the project for **iOS**.
2.  Compile the project using **Xcode**.
3.  Run the game on a **real iOS device** (AR features require a
    physical device).

## Marker Requirement

The game uses **marker-based AR detection**.

-   Use the provided **marker.jpg**.
-   When the camera detects the marker, the **Start Game button** will
    appear.
